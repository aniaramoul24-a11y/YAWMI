يومي – YAWMI (PWA)

طريقة النشر والتثبيت:
1) ارفعي محتويات هذا المجلد إلى خدمة استضافة مواقع ثابتة تدعم HTTPS مثل Netlify أو GitHub Pages.
2) افتحي رابط الموقع المنشور في Chrome أو Edge.
3) اختاري Install app / تثبيت التطبيق من قائمة المتصفح أو زر «تثبيت» داخل التطبيق إذا ظهر.
4) على الهاتف: من قائمة المتصفح اختاري «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».

ملاحظات:
- التطبيق يعمل دون اتصال بعد فتحه أول مرة وتحميل الملفات.
- البيانات محفوظة محلياً في المتصفح على نفس الجهاز، وليست متزامنة بين الأجهزة.
- لا توجد خدمة إشعارات خلفية مهيأة في هذه النسخة.
- لا تفتحي index.html مباشرة من القرص؛ يلزم HTTPS أو localhost حتى يعمل Service Worker والتثبيت.
